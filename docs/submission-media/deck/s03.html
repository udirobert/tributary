Why a footprint, not a lock

Declare before you write

A lock serialises everything and kills throughput. A declared footprint lets ten agents work at once and only stops the two that reach for the same file — and it stops them before the write, with a reason attached.

Why the model only sees the leftover

Residual, not total

Three-way merge settles most conflicts mechanically. Tributary sends the model only the hunk that survived the mechanical pass — smaller prompts, fewer hallucinated rewrites, and a diff you can actually read.

Why nothing lands on a green branch

Prove it in the sandbox

The repo's own verify command runs against the merged result in a container with no network and no privileges. Exit 0 or the revision never reaches the trunk.
