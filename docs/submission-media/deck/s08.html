REV A
  • Runtime
    Node 22 on Vultr · Workers runtime on Cloudflare — the same TypeScript runs in both homes
  • State
    Durable Object claim registry — one lock, serialised, no external database
  • Merge
    three-way in-process — git objects kept in a local memory filesystem
  • Gate
    docker run --network none --read-only — the repo's own verify command decides
  • Model
    Vultr Serverless Inference, GLM-5.3 — residual hunks only, no GPU held by the app
  • Front end
    one server-rendered sheet, no build step — the plan and the ledger are the same state
